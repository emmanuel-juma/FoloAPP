# FoloAPP
## About

Folo App is a learning platform designed to help students find study materials and educational resources. It supports learning in different fields, including Engineering, Medicine, Law, Philosophy, and more.

![image alt](https://github.com/emmanuel-juma/FoloAPP/blob/main/images/b50c67d0-47b2-4395-acc7-550f3bcfeda4.png)


## Features

- User login and logout.
- Search for books using the Open Library API.
- Find educational videos on YouTube.
- Read educational blog posts about studying, AI, books, and technology.
- Simple and user-friendly interface.

## Technologies Used

- HTML
- CSS
- JavaScript
- Open Library API
- YouTube Data API v3
